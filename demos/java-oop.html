🐾 1. Animal Hierarchy — Inheritance & Polymorphism

A classic OOP exercise using abstract classes, inheritance, and method overriding.

abstract class Animal {
    protected String name;
    public Animal(String name) { this.name = name; }
    abstract String speak();
    public String toString() { return name + " says: " + speak(); }
}

class Dog extends Animal {
    public Dog(String name) { super(name); }
    String speak() { return "Woof! 🐕"; }
}

class Cat extends Animal {
    public Cat(String name) { super(name); }
    String speak() { return "Meow! 🐈"; }
}

// Usage
Animal[] pets = { new Dog("Buddy"), new Cat("Mimi") };
for (Animal a : pets) System.out.println(a);
Buddy says: Woof! 🐕
Mimi says: Meow! 🐈

🏦 2. Bank Account — Encapsulation

A bank account class with private fields, getters/setters, and validation logic.

class BankAccount {
    private String owner;
    private double balance;

    public BankAccount(String owner, double initial) {
        this.owner = owner;
        this.balance = Math.max(0, initial);
    }

    public void deposit(double amount) {
        if (amount > 0) balance += amount;
    }

    public boolean withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
            return true;
        }
        return false; // Insufficient funds
    }

    public double getBalance() { return balance; }
}

📋 3. Student List — Collections & Sorting

Using ArrayList, Comparable, and Collections.sort() to manage student data.

class Student implements Comparable<Student> {
    String name;
    int score;

    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    public int compareTo(Student other) {
        return Integer.compare(other.score, this.score); // Descending
    }
}

// Sort by score
List<Student> students = new ArrayList<>();
students.add(new Student("Dadal", 92));
students.add(new Student("Yuki", 88));
students.add(new Student("Kim", 95));
Collections.sort(students);
1. Kim — 95 points
2. Dadal — 92 points
3. Yuki — 88 points
