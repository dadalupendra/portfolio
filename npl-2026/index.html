Free, local, no API key

Two engines work side by side: a deterministic NPL model built on the ball-by-ball data (runs on any phone or laptop, offline) and Ollama on your own machine for the reasoning layer.

ENGINE

Ollama is optional. The NPL model produces a full XI, scout report, win probability and data answers with zero setup. CPU-only laptop ma 8B model ले ~1–2 min lincha — qwen2.5:3b faster ho.

First time? 3 steps to enable the local LLM 
1) Ollama install: https://ollama.com/download (wa ollama-start.bat double-click)
2) ollama pull llama3.2   (wa qwen2.5:3b / llama3.1:8b)
3) ollama serve  →  yaha ENGINE: Ollama chhanus → Connect/Refresh.
Hosted site bhaye: OLLAMA_ORIGINS=* ollama serve
